\section*{Simplex}
The simplex algorithm was invented by Robert Dantzig in 1947 to solve Linear Programming problems. Dantzig proved that the feasible region (area that satisfies all constraints) of a Linear Programming problem forms a convex set. He also proved that the optimal solution of a LP problem is located at a vertex of the convex body of the feasible region. \\

Dantzig then used this theorems to create Simplex, an algorithm that moves through the vertices of the feasible convex body until finding the optimal solution to the problem. Simplex is a mechanical method that uses matrix operations to determine the solution. \\

To setup the simplex algorithm we will:
\begin{itemize}
    \item For each $\leq$ constraint add a slack variable $s_i$
    \item For each $\geq$ constraint add an excess variable $e_i$ and an artificial variable $a_i$.
    \item for each $=$ constraint add an artificial variable $a_i$
    \item for each artificial variable added:
    \begin{itemize}
        \item Add $Ma_i$ to the objective function if minimizing.
        \item Add $-Ma_i$ to the objective function if maximizing.
        \item M is a constant of a large value, but not infinite.
    \end{itemize}
\end{itemize}

\subsection*{Example}
\begin{center}
Maximize
Z = $x_1$ + $x_2$ \\
$x_1$ + 2$x_2$ $\leq$ 3 \\
4$x_1$ + 5$x_2$ $\geq$ 6 \\
7$x_1$ + 8$x_2$ $=$ 9 \\
\end{center}

Converts to

\begin{center}
Maximize
Z = $x_1$ + $x_2$ $- Ma_1 - Ma_2$ \\
$x_1$ + 2$x_2$ + $s_1$ $\leq$ 3 \\
4$x_1$ + 5$x_2$ + $e_1$ + $a_1$ $\geq$ 6 \\
7$x_1$ + 8$x_2$ + $a_2$ $=$ 9 \\
\end{center}

\newpage
Execution of Simplex algorithm:
\begin{enumerate}
    \item If there are any artificial variables, our first step should be to remove the Ms in their columns through matrix operations, leaving canonical vectors on artificial variable columns.
    \item if there are any negative\\textbackslash positive values in the first row (excluding Z and b) when maximizing\\textbackslash minimizing (respectively)
    \begin{enumerate}
        \item Identify the pivot
        \begin{enumerate}
            \item Indetify a column X with the most negative\\textbackslash positive (maximizing\\textbackslash minimizing), divide all values on column b with their respective value on X.
            \item Exclude 0s and negative values
            \item The pivot will be the cell on column X on the row with the \textbf{smallest} division result.
        \end{enumerate}
        \item Through matrix operations, create a canonical vector on the column of the pivot, leaving $1$ exactly on the pivot cell.
        \item Go to 2
    \end{enumerate}
    \item The simplex table will contain the optimal solution.
    \begin{itemize}
        \item In column b, the first cell shows the value of Z.
        \item Every variable with a non-canonical vector in their column has a value of 0.
        \item Variables with a canonical vector in their column have a value of what the b column has on the row where they have a 1.
    \end{itemize}
\end{enumerate}
